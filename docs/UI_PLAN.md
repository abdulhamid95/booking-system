# UI_PLAN — خطة الواجهات (MVP)

## الشاشات الأساسية

### العميل (صفحات عامة)

| # | الشاشة | الوظيفة |
|---|--------|---------|
| 1 | صفحة الحجز العامة | يختار العميل الخدمة والموظف والوقت ويرسل طلب الحجز دون تسجيل دخول |
| 2 | شاشة تأكيد الحجز | تظهر بعد الحجز وتعرض ملخصه (الخدمة، الموظف، الوقت، كود التأكيد) |

### صاحب المنشأة (لوحة التحكم)

| # | الشاشة | الوظيفة |
|---|--------|---------|
| 3 | صفحة التسجيل | إنشاء حساب ومنشأة جديدة في خطوة واحدة |

## رحلة العميل

### الدخول إلى صفحة الحجز

1. يحصل العميل على رابط صفحة الحجز الخاصة بالمنشأة (`/book/{business_id}/`)
2. يفتح الصفحة مباشرة — لا يحتاج إلى تسجيل دخول
3. تظهر له قائمة الخدمات المتاحة (الاسم والمدة لكل خدمة)

### اختيار الخدمة والموظف

4. يختار الخدمة التي يريدها
5. تظهر له قائمة الموظفين المرتبطين بهذه الخدمة فقط
6. يختار الموظف المناسب

### اختيار الوقت

7. يختار التاريخ المطلوب
8. تظهر له الأوقات المتاحة فقط (الأوقات المحجوزة لا تظهر أو تكون غير قابلة للاختيار)
9. يختار الوقت المناسب

### إدخال البيانات وإرسال الحجز

10. يُدخل بياناته: الاسم، رقم الهاتف، البريد الإلكتروني (اختياري)
11. يضغط على "تأكيد الحجز"
12. إذا كان الوقت محجوزاً ← تظهر رسالة خطأ واضحة ويُطلب منه اختيار وقت آخر

### التأكيد

13. عند نجاح الحجز ← يُحوَّل إلى شاشة تأكيد الحجز
14. تظهر رسالة نجاح تتضمن: اسم الخدمة، اسم الموظف، التاريخ والوقت، كود التأكيد

## رحلة صاحب المنشأة

### الإعداد الأولي (Onboarding)

1. يفتح الموقع ويضغط على "إنشاء حساب"
2. يُدخل: اسمه، بريده الإلكتروني، كلمة المرور، اسم المنشأة، نوع المنشأة
3. يتم إنشاء الحساب والمنشأة دفعة واحدة، ويُحوَّل تلقائياً إلى لوحة التحكم

### تجهيز المنشأة

4. يذهب إلى **إدارة الخدمات** ← يضيف خدمة أو أكثر (الاسم، المدة، السعر)
5. يذهب إلى **إدارة الموظفين** ← يضيف موظفاً أو أكثر (الاسم، الهاتف)
6. يربط كل موظف بالخدمات التي يقدمها
7. يحدد أوقات عمل كل موظف (الأيام والساعات)

> عند هذه النقطة تصبح المنشأة جاهزة لاستقبال الحجوزات.

### الاستخدام اليومي

8. يدخل إلى **لوحة التحكم** ← يرى ملخص الحجوزات القادمة
9. يذهب إلى **قائمة الحجوزات** ← يتابع جميع الحجوزات (القادمة / المنتهية)
10. يستطيع إلغاء أي حجز عند الحاجة
11. عند الحاجة يعود إلى **إعدادات المنشأة** لتعديل البيانات أو أوقات العمل

## وصف الشاشات

### الشاشة 1 — صفحة الحجز العامة

- **الهدف:** تمكين العميل من حجز موعد بخطوات واضحة دون تسجيل دخول.
- **أهم العناصر:** قائمة الخدمات المتاحة، قائمة الموظفين المرتبطين بالخدمة، الأوقات المتاحة فقط، نموذج بيانات العميل، زر "تأكيد الحجز".
- **أهم الإجراء:** اختيار الخدمة ← الموظف ← الوقت ← إرسال طلب الحجز.

---

### الشاشة 2 — شاشة تأكيد الحجز

- **الهدف:** إعلام العميل بنجاح الحجز وإعطائه مرجعاً للرجوع إليه.
- **أهم العناصر:** رسالة نجاح واضحة، ملخص الحجز (الخدمة، الموظف، التاريخ والوقت)، كود التأكيد.
- **أهم الإجراء:** قراءة التأكيد وحفظ كود الحجز.

---

### الشاشة 3 — صفحة التسجيل

- **الهدف:** إنشاء حساب ومنشأة جديدة في خطوة واحدة.
- **أهم العناصر:** حقول الاسم والبريد وكلمة المرور واسم المنشأة ونوعها، زر "إنشاء الحساب".
- **أهم الإجراء:** ملء البيانات والضغط على إنشاء الحساب للدخول مباشرة إلى لوحة التحكم.

---

### الشاشة 4 — صفحة تسجيل الدخول

- **الهدف:** السماح لصاحب المنشأة بالدخول إلى لوحة التحكم.
- **أهم العناصر:** حقل البريد الإلكتروني، حقل كلمة المرور، زر "تسجيل الدخول"، رابط إنشاء حساب جديد.
- **أهم الإجراء:** إدخال بيانات الدخول والضغط على تسجيل الدخول.

---

### الشاشة 5 — لوحة التحكم الرئيسية

- **الهدف:** إعطاء صاحب المنشأة نظرة سريعة على وضع منشأته.
- **أهم العناصر:** عدد الحجوزات القادمة اليوم، عدد الموظفين النشطين، عدد الخدمات المتاحة، قائمة مختصرة بأقرب الحجوزات.
- **أهم الإجراء:** مراجعة الحجوزات القادمة والانتقال السريع إلى أي قسم.

---

### الشاشة 6 — إدارة الخدمات

- **الهدف:** تمكين صاحب المنشأة من إدارة قائمة الخدمات التي تقدمها منشأته.
- **أهم العناصر:** جدول الخدمات (الاسم، المدة، السعر، الحالة)، زر إضافة خدمة، نموذج إضافة/تعديل، زر تعطيل.
- **أهم الإجراء:** إضافة خدمة جديدة أو تعطيل خدمة قائمة.

---

### الشاشة 7 — إدارة الموظفين

- **الهدف:** تمكين صاحب المنشأة من إدارة الموظفين وربطهم بالخدمات.
- **أهم العناصر:** قائمة الموظفين (الاسم، الهاتف، الخدمات المرتبطة، الحالة)، زر إضافة موظف، خيار ربط الموظف بالخدمات.
- **أهم الإجراء:** إضافة موظف وربطه بالخدمات التي يقدمها.

---

### الشاشة 8 — قائمة الحجوزات

- **الهدف:** منح صاحب المنشأة رؤية كاملة لجميع حجوزات منشأته.
- **أهم العناصر:** جدول الحجوزات (اسم العميل، الخدمة، الموظف، التاريخ والوقت، الحالة)، تصفية بين القادمة والمنتهية، زر إلغاء الحجز.
- **أهم الإجراء:** مراجعة الحجوزات وإلغاء أي حجز عند الحاجة.

---

### الشاشة 9 — إعدادات المنشأة

- **الهدف:** تعديل البيانات الأساسية للمنشأة وتحديد أوقات العمل.
- **أهم العناصر:** حقول بيانات المنشأة (الاسم، النوع، الهاتف)، جدول أوقات العمل لكل موظف، زر "حفظ".
- **أهم الإجراء:** تحديد أوقات العمل لكل موظف حتى تظهر الأوقات المتاحة للعملاء بشكل صحيح.

---

### الشاشة 10 — حجوزاتي (الموظف)

- **الهدف:** إطلاع الموظف على مواعيده الشخصية القادمة فقط.
- **أهم العناصر:** قائمة الحجوزات المرتبطة بهذا الموظف (اسم العميل، الخدمة، الوقت) مرتبة زمنياً.
- **أهم الإجراء:** الاطلاع على المواعيد القادمة والتحضير لها.

---

## خريطة الواجهات

### منطقة العميل (Public)

```
رابط المنشأة العام
/book/{business_id}/
         │
         ▼
┌─────────────────────┐
│  صفحة الحجز العامة  │
│  ① اختيار الخدمة    │
│  ② اختيار الموظف    │
│  ③ اختيار الوقت     │
│  ④ إدخال البيانات   │
│  ⑤ تأكيد الحجز      │
└─────────┬───────────┘
          │ نجاح
          ▼
┌─────────────────────┐
│  شاشة تأكيد الحجز   │
│  - ملخص الحجز       │
│  - كود التأكيد      │
└─────────────────────┘
          │ فشل (وقت محجوز)
          ▼
     رسالة خطأ
  (يعود لاختيار وقت آخر)
```

      │                                                   │
      └──► /login/  ◄──────────────────────────────────── ┘

                ▼
     ┌──────────────────────────┐
     │   /dashboard/            │
     │   لوحة التحكم الرئيسية   │
     │   - حجوزات اليوم         │
     │   - موظفون نشطون         │

services/  staff/          bookings/          settings/

```

    │
    ▼
/staff/my-bookings/
حجوزاتي

```

### الانتقالات الأساسية بين الشاشات

| من | إلى | الحدث |
|----|-----|-------|
| التسجيل | لوحة التحكم | بعد إنشاء الحساب بنجاح |
| تسجيل الدخول | لوحة التحكم | بعد الدخول بنجاح |
| لوحة التحكم | قائمة الحجوزات | ضغط على "عرض الكل" |
| لوحة التحكم | إدارة الخدمات | ضغط على قسم الخدمات |
| لوحة التحكم | إدارة الموظفين | ضغط على قسم الموظفين |
| صفحة الحجز العامة | شاشة التأكيد | بعد إرسال الحجز بنجاح |
| أي شاشة في Dashboard | تسجيل الدخول | انتهاء الجلسة / تسجيل الخروج |

### ملاحظات للمصمم

- **صفحة الحجز العامة** هي الأهم — الـ Backend جاهز بالكامل لها.
- لوحة التحكم تحتاج **Sidebar ثابت** يحتوي روابط: الرئيسية، الخدمات، الموظفين، الحجوزات، الإعدادات.
- الشاشات العامة (العميل) منفصلة كلياً عن لوحة التحكم — لا يوجد تداخل.
- الموظف يدخل بنفس صفحة تسجيل الدخول لكن يرى واجهة مختلفة (حجوزاته فقط).
